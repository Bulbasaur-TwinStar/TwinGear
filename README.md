# ⚔️ TwinGear v2.1 – Equipped iLvl, Gear Audit & Raid Check (MoP 5.4.8)

Lightweight, fast, and accurate character/inspect equipment audit addon built specifically for **TwinStar WoW – Mists of Pandaria 5.4.8** (Helios & Persés).

* **Author:** Bulbasaur of TwinStar

---

## ✨ Key Features
* **Real Equipped Item Level:** Instant and accurate equipped iLvl calculation for yourself, your inspected target, and raid members.
* **Complete Equipment Audit:** Automatically detects missing enchants, empty gem sockets, missing belt buckles, and PvP items in PvE gear at a glance.
* **Raid Check & Sync:** Fast group inspection and raid gear overview with zero FPS impact during 25-man encounters.
* **Universal Compatibility:** Works seamlessly across all client languages and alongside any UI (**DragonUI, ElvUI, or default Blizzard UI**).

## 📥 Download & Installation
1. Click on **`TwinGear_v2.1_TwinStar_MoP.zip`** in the file list above, then click the **Download raw file** button (arrow icon on the right).
2. Extract the `.zip` archive.
3. Copy the **`TwinGear`** folder directly into `World of Warcraft\Interface\AddOns\` (without any parent folder).
4. Restart the game client (or type `/reload` if the game is already running).
